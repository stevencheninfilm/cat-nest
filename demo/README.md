# 测试调试存档

`/cat-nest/test/` 与 `/cat-nest/steven/`、`/cat-nest/evian/` 使用完全相同的 `src/entry.js`、`src/main.js`、样式和素材。`demo/` 只保留测试数据、模拟 transport、预设判词和调试控制台；不再包含应用副本或独立 Vite 构建。

测试存档的进度、身份、待处理操作、小游戏和判官会话仅在当前页面内存中存在，刷新/重新进入恢复默认，各标签页独立。模拟接口禁止回退到真实接口，不写入正式 GitHub 存档，不访问真实案件，不调用付费 AI。新手指引也仅记录本次访问：每次进入小窝或餐厅体验、选择身份后自动显示对应向导，旧的已读记录不再跳过引导；本次访问中仍可关闭或手动重看，不影响正式存档的引导记录。

公开 Demo 和本地测试均使用 `/cat-nest/test/`：未指定页面时，选择身份后默认进入猫猫餐厅。每次打开或刷新默认静音，可在声音设置中手动开启；不更改正式存档的入口和声音偏好。

所有游戏规则、乐观更新、成长领取、图鉴、双人照顾、模型和页面布局都来自共用 `src/`。控制台只通过同版 reducer 生成测试数据，支持延迟、断线、失败回退和模拟伙伴。

一次运行 `npm test`、`npm run build` 即覆盖所有入口。构建检查要求三个入口 HTML 完全相同，且入口下不存在重复的 assets/model 目录。详细架构和新建存档说明见 `../docs/shared-save-architecture.md`。本地仍只复用 5174 共享预览。
