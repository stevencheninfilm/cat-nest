# 独立网站演示版

公开入口：`https://stevencheninfilm.com/cat-nest/test/`。

`demo/app/` 是冻结的养成前端快照，`demo/public/` 和 `demo/model/` 一并冻结页面素材和模型。正常 `/cat-nest/` 继续从根目录 `src/` 构建，演示版单独构建到 `dist/test/`。演示版不会读取正式房间、写正式 GitHub 存档、使用真实法庭数据或请求 OpenAI。模型为已购 Mage Cat 的网页运行素材，作者 Nekueda；保留项目内既有授权与署名。

首次访问会展示三步新手指引，再选择身份进入小窝；完成后不会重复弹出，可在控制台点击「重新查看指引」。只有指引已读状态保存在 `catnest.demo.ui.v1.*`，不包含游戏进度。

页面底部的金色「演示控制台」按钮提供喂食、装扮、成长、小游戏、双方照顾记录、图鉴和日记入口，以及伙伴互动、食物余量、成长解锁、五种判词效果和演示重置。弹窗内也保留清晰的演示入口。双人小游戏由模拟伙伴接招。

演示进度只在本次页面内存中临时存在，不写入 localStorage、sessionStorage 或云端。刷新、重新打开以及从浏览器历史返回都会恢复默认状态；不同标签页各自独立，不同步进度。身份、成长、金币、食物、图鉴、游戏、法庭记录和待处理请求全部重新开始。页面启动会移除旧版 `catnest.demo.v1.*` 演示存档，保留正式版数据。旧法庭/房间 URL 参数会清除，避免恢复已结束的演示案件。此版是展示与模拟接口调试环境，不是正式后端的联调环境。

调试支持 0/650/2500/6000 ms 延迟、下一次写操作拒绝、网络断开恢复、伙伴在线状态和导出请求日志。日志只含请求路径、状态、版本与调试配置，不包含陈词或图片。养成请求使用与正式版相同的 `createCloudRoom` 乐观更新及回退逻辑，再由闭合的演示 transport 转给同版 reducer；未识别的主机和接口直接拒绝，没有转发正式接口的回退分支。

本地继续使用共享预览 `http://127.0.0.1:5174/test/`。不启动其他端口。

验证和发布：

```sh
node --test tests/demo.test.mjs
npm run build
node scripts/build-demo.mjs
```

GitHub Pages 工作流先构建正式版，再构建演示版并合并发布。不要把共享目录其他未完成的 `src/` 修改一同提交。正式版文件需要与上一发布提交逐个比对。演示快照的文件摘要在 `snapshot.json`；后续升级演示时应单独审查快照变更，并重新执行隔离与失败回退测试。
