# 猫猫新手指引

入口为主页右上角书本图标，设置里可打开实景指引或图文手册。原一分钟领养、照顾、领取气泡和邀请流程继续使用正常操作与保存回执，完成后衔接实景导览。

- `src/game-guide.js` 管理导览、手册、阅读进度和板块首次进入提示；只写本机的 `catnest.handbook.v1.<role>` 阅读偏好，不写养成状态，不创建法庭，不开局，不消费猫爪币。
- `src/game-guide-tour.js` 维护实际页面目标。整轮入门介绍入口，小游戏、判官、装扮的详细内容延后到首次打开相应板块；板块内的「？」和手册均可重看。
- `src/game-guide-content.js` 提供 15 个图文章节、全部食物和 13 款小游戏说明。食物、冷却、玩法和等级门槛从现有规则模块读取。
- 目标框按当前 `getBoundingClientRect()` 连续跟踪，减去导览容器原点并留出 4px 边距。弹窗动画、滚动、字体加载和布局变化都会重新对齐；关掉导览立即停止跟踪。
- 阅读偏好沿用存档的 scoped storage，并按身份隔离；测试存档只使用测试 UI 偏好。板块小课堂不覆盖整轮导览的暂停位置。
- 原功能等级门槛仍生效；未解锁的内部页面不在实景导览中打开，图文手册可以提前查阅。3D 小屋仍为「暂未开放」。

## 猫猫餐厅 · 2026-10-19

餐厅沿用小窝的金色实景高亮、箭头、透明小猫向导和奶油色对话卡。十四步覆盖开张、两种钱包、接单、取料、工序计时、送餐、结账成长、菜谱、研发、员工能力、休息室、设施升级和装扮。点击高亮框只前进阅读，不点击背后的游戏操作。

- 选择身份、餐厅快照就绪且没有其他弹窗时，首次进入自动介绍；关闭其他弹窗后才启动，暂停过或完成过不反复打扰。
- 钱包旁小书、营业信息和玩法说明均可重新进入。目录可直接跳转任一环节；暂停保留当前位置，完成后再次打开从头重看。原厨房「操作教程」改为五步短课堂，不覆盖整轮引导的暂停位置。
- `src/restaurant-guide.js` 只写当前存档适配器中的 `catnest.restaurant-guide.v1.<role>` 阅读偏好，两位主人分别记录。不写房间、钱包、经验、员工、订单、玩法队列或小窝原指引记录，也不调用引导管理的元数据接口；测试使用既有独立 UI 偏好适配器。
- 导航仅切换真实场景与面板，不造客、不替玩家接单、派工、探索、升级或解锁。灰色资源继续使用正式等级与货币条件。阅读时暂停自然新客，已开始工序继续原本计时。
- 高亮框持续跟踪动画、滚动与目标重绘。厨房视角的滚动先在下一帧完成，然后再定位引导目标；短屏场景目标靠上滚动，对话卡给顶部暂停和目录按钮留出空间。退出餐厅、切换身份或销毁页面立即停止跟踪。

回归包括首次触发条件、暂停/完成/重播、目录、短教程独立进度、身份与存档隔离、损坏/不可写偏好、目标移动、导航失败和关闭清理。共享 5174 预览中走完十四步，并检查 390px、320px 手机布局；效果与只读几何记录位于 `artifacts/restaurant-guide/`。
