# 猫猫新手指引

入口为主页右上角书本图标，设置里可打开实景指引或图文手册。原一分钟领养、照顾、领取气泡和邀请流程继续使用正常操作与保存回执，完成后衔接实景导览。

- `src/game-guide.js` 管理导览、手册、阅读进度和板块首次进入提示；只写本机的 `catnest.handbook.v1.<role>` 阅读偏好，不写养成状态，不创建法庭，不开局，不消费猫爪币。
- `src/game-guide-tour.js` 维护实际页面目标。整轮入门介绍入口，小游戏、判官、装扮的详细内容延后到首次打开相应板块；板块内的「？」和手册均可重看。
- `src/game-guide-content.js` 提供 15 个图文章节、全部食物和 13 款小游戏说明。食物、冷却、玩法和等级门槛从现有规则模块读取。
- 目标框按当前 `getBoundingClientRect()` 连续跟踪，减去导览容器原点并留出 4px 边距。弹窗动画、滚动、字体加载和布局变化都会重新对齐；关掉导览立即停止跟踪。
- 阅读偏好沿用存档的 scoped storage，并按身份隔离；测试存档只使用测试 UI 偏好。板块小课堂不覆盖整轮导览的暂停位置。
- 原功能等级门槛仍生效；未解锁的内部页面不在实景导览中打开，图文手册可以提前查阅。3D 小屋仍为「暂未开放」。

## 插画

内置 imagegen 生成 7 张主题插画及 1 张透明背景向导。网页使用 `public/assets/game-guide/v1/` 内的 WebP，共约 1.1MB；文字由 HTML 展示。完整生成提示词见 `docs/assets/game-guide-v1.json`。

## 验证

`tests/game-guide.test.mjs` 覆盖规则目录、延后板块路线、存档与身份隔离、移动目标持续对齐、暂停续读、板块首次提示与主动重看、已完成导览重走后的续读，以及等级门槛。

手机 436×831 的共享 `/test/` 预览核对：喂食分类、确认、双人状态、照顾标签和日记标签的框与实际目标相差恰为四边 4px 留白；小游戏、判官、装扮均在玩家主动打开后首次触发，重新查看可正常显示。阅读不增加成长或扣除猫爪币。

本次相关测试连同原入门流程、共享构建、等级门槛测试共 27 项通过。共享构建通过所有注册入口一致性检查。本地验收截图保存在 `artifacts/game-guide/`。
