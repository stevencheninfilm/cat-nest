# 成长阶段视觉

| 等级 | 爱心材质 |
| --- | --- |
| 1–10 | 橙色果冻 |
| 11–20 | 镭射糖果 |
| 21–30 | 透明水晶 |
| 31–40 | 蜜糖琥珀 |
| 41–50 | 金箔蜜糖琥珀 |
| 51–60 | 红宝石 |
| 61–70 | 蓝宝石 |
| 71–80 | 星云欧泊 |
| 81 起 | 钻石鎏金，等级继续增长 |

当前材质由已保存的累计 XP 和现有 `levelInfo` 等级曲线推导，不新增存档字段。阶段配置在 `src/growth-stages.js`，所有成长气泡、领取爱心、等级徽章、成长条和阶段面板都使用此配置。

点击右上角等级可查看全部阶段、当前等级成长进度和下一阶段解锁等级。点击卡片只预览材质，不更改成长值或装备外观。确认领取跨越阶段边界后，飞行爱心保留领取前的材质，成长条和剩余气泡显示新材质，随后展示阶段升级提示。正在操作其他弹窗、猫猫判官或沉浸陪伴时，提示等待返回小窝后再出现；初次加载存档不补弹升级提示。

阶段面板、放大预览和卡片中的进度条采用本阶段累计成长，而小猫主界面的成长条仍展示本级进度。阶段起点为到达该阶段第一级所需的累计成长，阶段目标为下一阶段起点减去本阶段起点；进度为本阶段已领取成长与目标的比值。未解锁阶段灰显加锁并显示 0%，已完成阶段显示 100%。例如 1–10 级的目标为 2,550 点，积累 1,275 点显示 50%，还差 1,275 点解锁镭射糖果。到达 11 级后，11–20 级从 0 / 5,550 开始。待领取气泡不提前计入进度。81 级起没有下一材质目标，解锁后显示「全部解锁」，不使用无穷大作为分母。

九张立体渲染素材采用内置 image_gen 生成，按用户确认的两张参考图统一鼓起双瓣、厚度、柔和尖角及宽亮高光。运行时文件位于 `public/assets/growth-hearts/v1/`，为保留透明通道的 512×512 WebP。完整提示词保存在 `docs/growth-heart-prompts.json`。正常图片加载使用预渲染素材；加载失败时保留共享 Three.js 立体模型及 SVG 回退。

进度条另有九张内置 image_gen 生成的立体胶囊材质，位于 `src/assets/growth-bars/v1/`，完整提示词在 `docs/growth-bar-prompts.json`。素材统一为 128px 高并保留透明通道；两端各取 64px，以横向三段拉伸保留圆头，中段随真实成长比例伸缩。主界面和阶段面板共用对应阶段材质，零进度仍保持空条。高光来自静态材质，领取时仅短暂轻微亮起。

云端存储、双方身份、领取请求、GitHub SHA 原子冲突重试、永久领取回执和客户端去重流程未增加视觉状态写入。外观预览及升级提示不会派发互动或领取动作。

验证覆盖阶段边界、旧存档累计 XP、预览不改变当前阶段、确认领取后升级、重复领取拒绝、未领取气泡长期保留、服务重启恢复、双端 SSE 同步及并发单次计入。使用独立本机模拟存档检查 320px、390px 和桌面布局，未操作线上用户成长数据。
