# 单人和人机小游戏本机运行

原先单人、人机每次开局、翻牌、落子和电脑回合都经过 GitHub 存档写入。图片预加载无法消除这段往返；本次将新开的单人和电脑对局放到本机规则引擎执行，结束后后台提交一份操作记录。双人联机仍使用原有服务器回合和隐藏信息校验。

- 十三款游戏的单人、电脑模式即时开局和响应，不等待小窝存档。进入游戏屋时预加载、解码十张封面与翻牌猫猫素材，同时预热棋类计算 Worker。资源失败不阻止开局，缺少 Worker 时使用同一份本机算法。
- 电脑思考等待为 140 毫秒加设备计算时间；五子棋、井字棋和四子棋优先在 Worker 运算。翻牌不匹配展示 650 毫秒后自动收起，限时玩法保留 1 秒准备倒计时。双人规则与已存在的旧服务器对局继续保留；旧局可以继续联网完成，也可以从模式选择新开本机对局。
- 对局中途没有存档 POST。限时游戏检查点只更新本机记录，反应力成绩使用本机点击时间，不再计入上传耗时。结束时上传输入、时间和随机种子，服务器用同一规则重放，拒绝任意分数、胜负、经验值、双人伪装、未完成对局和越界日志。
- 结果在后台核对时仍可再开一局。核对成功才更新猫友胜局、每日小游戏成长额度及成长气泡；点击气泡才增加经验。额度仍是小窝每日合计 50 点，上传当日以服务器额度结算，重复上传和跨日重放均不能再次获奖。
- 每局有永久唯一回执，已领取奖励和操作短日志滚动后仍可去重。新的本机对局不覆盖正在进行的共享对局。大输入日志不复制进服务器最近 100 项操作日志，只保存小回执。
- 按现有存档缓存前缀及男方/女方分别保存当前局和待上传结果；关闭页面前落盘，刷新可恢复。测试入口继续使用临时隔离存储，刷新恢复测试默认。最多保留 20 局待上传结果；达到上限提示先联网保存。
- 页面资源加载完成后可以断网继续玩，联网后自动尝试上传，也可点“重试上传”。这不是完整离线安装包：首次进入页面和未缓存素材仍需网络，双人实时对战仍需联网。本机存储被系统清理或禁用时，未上传的记录不能保证恢复。

## 验证与发布

回归覆盖全部 26 种单人/电脑组合、本地即时翻牌、140/650 毫秒时机、Worker 失败与取消竞态、断网续玩、刷新恢复、按存档与身份隔离、HTTP 结算、并发重复提交、服务重启、操作日志滚动、奖励领取和每日额度。六个入口继续共用一份构建；Docker 运行阶段加入共享本机重放模块，不增加服务或费用。

本地复用 5174 预览；隔离副本只测试和构建，不另开前端预览端口。真实手机帧率尚待设备验证，自动测试不替代真机视觉或 FPS。精确补丁和结果位于 `artifacts/local-games-20261016/`。
