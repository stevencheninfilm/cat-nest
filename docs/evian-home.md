# Evian 独立存档

入口为 `/cat-nest/evian/`。双方选择男方或女方后，都连接固定云端房间 `6858d44c3a9ce3b77ea7c5334b4acd02`。此房间通过既有云端创建接口单次建立：1200 钱币、0 成长、0 亲密度、空日记、空待领取气泡、初始装扮、未使用的照顾额度。每次访问只读取原房间，刷新、换设备和重新发布均不会重置存档或重新发放钱币。

原入口继续使用原共同小窝接口。Evian 通过同一 API 的既有 `/api/rooms/:id`、actions 与 SSE 接口共享进度，角色仍使用固定的男方和女方身份。房间缺失或读到其他房间时显示连接错误，不自动建立替代房间。云端领取与冲突重试规则沿用既有实现。

Evian 所有主应用本机缓存和待保存队列增加 `evian:` 前缀，避免带入原小窝的未提交操作或缓存进度。开发预览继续复用 5174，同一预览服务中的 Evian 使用单独的本地文件。

Vite 发布时生成 `evian/index.html`，通过 `<base href="../">` 复用父目录的构建资源；品牌首页链接仍停留在 Evian 入口。无需新增后端服务、环境变量或重启正式 API。
