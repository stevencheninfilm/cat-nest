# 手机表情与装扮预览

表情和装扮面板在小屏幕上使用独立预览布局：竖屏时猫猫在上、控制面板在下；横屏时左右分开。猫猫和面板至少间隔 12px，预览区域限制在原小窝及可见视口内，不裁去猫猫来容纳面板。

`src/cat-preview-layout.js` 根据 `visualViewport` 的宽高与偏移计算位置，监听 Safari 工具栏引起的视口变化与旋转。桌面普通尺寸保留既有布局。`src/cat-preview.css` 只在预览期间生效；临时收起周围状态、成长气泡、说话气泡与操作入口，关闭或切换面板后恢复。装扮选项与表情/动作列表在面板内部滚动，不滚动网页。

外观预览、保存按钮、关闭时撤回未保存外观及本地表情行为沿用既有流程；本次没有改变任何存档或装扮价格，也未开放 3D 小屋。

验证覆盖 320×568 至 430×932 的常见竖屏、568×320 至 932×430 的横屏、Safari 可见视口偏移、带边框的小窝、视口变化和关闭恢复。56 项布局及相关回归通过，带正式 API URL 的生产构建和 Steven/Evian/Test/Todd 共用入口检查通过。证据在 `artifacts/cat-preview-layout-20261015/validation.json`。

未启动新的预览服务器，未操作玩家真实存档。浏览器来源此前仍被拒绝，未绕过限制；修复后的浏览器视觉与手机实测尚未完成，本次尚未发布。
