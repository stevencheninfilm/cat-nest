# 进入小窝的等待反馈

选择身份后，在猫猫位置显示轻量半透明灰玻璃加载卡片（底色不透明度约 22%–38%，背后画面去饱和），带沙漏与细金色流动进度条。状态来自实际生命周期：正在连接服务器并读取存档 → 正在建立实时连接 → 准备小猫模型与装扮。云端存档、连接和模型均就绪后立即隐藏；两者加载先后顺序不影响结果。

服务器首次启动和读取存档没有可测量的整体百分比，因此使用不确定进度条和明确的阶段文字，不显示模拟百分比或倒计时。首次连接提示可能需要约一分钟。网络中断显示恢复连接；错误和满员停止加载动画并提供重新连接按钮，继续复用原有 `startCloud()`，不清除存档、不重复提交互动。

模型加载失败时移除等待卡片，保留插画兜底及原有模型重试入口。动态模块导入失败也可以重试，避免一直显示等待。无身份时不显示卡片，以免与身份选择页重叠；模型加载完成后仍会等待服务器确认。系统减少动态效果时，沙漏与进度条保持静态。

实现为 `src/home-loading.js`、`src/home-loading.css`，`src/main.js` 仅接入状态刷新、模型生命周期和重试按钮。没有改动云端存档格式、成长领取逻辑或服务器接口。上线只需要更新前端构建。
