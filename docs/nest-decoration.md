# 共同布置小窝

首页右侧「布置小窝」直接进入现有 3D 小屋的装修模式；正式小窝底部也保留入口。3D 小屋中的「布置」能展开同一面板。桌面上面板位于右侧，手机上为下半屏的玻璃面板；房间切到全景，实际家具与平面图同步显示。

`/test/` 使用同一份装修代码，在主界面与演示控制台都能进入。收藏、摆放、配色、升级和家具照顾走隔离的演示接口，仅保存在本次访问的内存中；刷新后恢复默认家具与等级，不写入 Steven 或 Evian 的存档。装修时收起浮动演示控制台入口，避免覆盖手机上的摆放操作。

## 家具、收藏和成长

- 家具页可点选已有家具，再点房间地板或平面图摆放，也可拖动平面图中的家具。提供四向微调、90 度转向和收纳；新收藏的家具可以「找个空位」后再微调。收纳不丢失收藏。
- 默认拥有音乐桌、猫床、夜灯、沙发和玩具球。可用现有猫爪币收藏云朵软垫（100）、猫爪抓柱（160）、薄荷盆栽（120）、星月地毯（180）、故事书架（260）、双人纪念架（360），每件一份。购买不自动摆放，也不产生照顾奖励。
- 四套免费配色为奶油暖木、薄荷森林、星夜薰衣草和蜜桃日落。墙面、木色和软装一起变换，首页也有对应的轻微氛围色。科幻空间保留较深的配色层次。
- 暖心角落可摆 7 件；280 币升级为星光小窝，可摆 10 件，实际房间新增灯串并解锁地毯、书架；再花 650 币升级为「我们的家」，可摆 12 件，新增双心纪念牌并解锁纪念架。装修等级与猫咪成长等级分别保存。

## 共同存档与冲突

`state.nest` 保存版本、等级、配色、收藏、逐件摆放、布置版本和最近编辑者。旧档自动获得默认家具，原有金币、成长、照顾账本、装扮和双人记录均保留。

`nest-buy`、`nest-place`、`nest-store`、`nest-palette` 和 `nest-upgrade` 走现有 action 队列。界面先预览，再等待存档确认；保存状态明确区分正在保存、已保存、尚未保存和本机保存。失败回退到已确认布置，暂时网络故障保留原操作编号重试。后端先提交 GitHub 存档，再通过 SSE 确认和广播。

每个操作只变更一件家具或一个选项，SHA 冲突后会基于最新档重放，因此不同家具的同时修改可以合并。同一件家具以最后一次通过校验并保存的操作为准；无效、重叠或堵路的后续摆放被拒绝。收藏和升级检查最新余额，重试不会重复扣币。两位玩家都能接着修改，面板显示最近编辑者。

后端与前端使用同一份家具清单和摆放校验：所有家具必须在室内，实体家具不能重叠，猫咪起点、机器人与门口保留通路；实际 A* 导航根据当前摆放计算碰撞和可达入口。地毯不阻挡行走，可以铺在家具下面。转向后的占地也参与检查。

## 家具实际用途

点家具可让猫咪走近、播放原生互动；房间中的照顾按钮和布置页的「猫猫来用」会在到达后执行实际照顾：

| 家具 | 照顾用途 |
| --- | --- |
| 猫床、云朵软垫 | 休息恢复活力；已经熟睡时可叫醒 |
| 玩具球、抓柱、音乐桌 | 玩耍提升开心，按原规则消耗活力并生成奖励 |
| 沙发、故事书架 | 温柔摸摸，提升开心 |
| 夜灯、盆栽、地毯、纪念架 | 灯光、闻闻叶子、走过和纪念互动，不额外发奖 |

实际照顾仍是原来的 `pet`、`play`、`sleep`，附带已摆放的 `furniture` 来源。共用原有次数、冷却、能量检查与双人照顾记录，成长仍须回主页领取气泡。自动探索和装修不会偷偷消耗照顾次数。后端拒绝未拥有、未摆放或用途不匹配的家具照顾；永久成长收据保留家具来源，避免重试和旧操作编号被挪作其他照顾。

## 验证

`tests/nest-decor.test.mjs` 覆盖旧档迁移、价格和等级、摆放与通路、真实家具碰撞、实际照顾限制、保存恢复、主题材质和升级装饰。`tests/nest-decor-cloud.test.mjs` 验证独立存档实例的并发合并、余额竞争、丢失确认后重试、失败保存、坏档保护，以及真实 SSE 双角色广播。客户端延迟确认、远端修改重放和拒绝回退位于 `tests/optimistic-cloud.test.mjs`。

共享预览中的 `http://127.0.0.1:5174/tests/nest-decor-preview.html` 是独立验收示例，使用独立 sessionStorage 和示例金币，不写入真实共用存档。可以切换示例编辑者并重置示例。没有启动其他预览端口。
