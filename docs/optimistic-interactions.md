# 即时互动与云端确认

本次为前端响应优化，服务器仍负责冷却、次数、币、成长领取和双人冲突的最终验证。

## 显示流程

发送请求后，使用现有 `reduceAction` 计算临时页面状态，立即回应摸摸、逗猫、休息、喂食、换装、改名及成长领取。气泡领取会立即飞入进度条；不同气泡可以连续领取，请求按原编号排队。相同气泡未确认前不能重复提交。普通照顾仍遵守保存等待和冷却限制。

云端确认后，用实际快照替换临时显示。同一请求通过 SSE 和 HTTP 返回多次，也只播放一次动画、记录一次结果。材质升级庆祝以已确认成长值为准，不能因后一个排队请求的临时成长提前触发。

云端拒绝操作时，移除相应临时变化，取消飞行特效和小猫动作，恢复最新已确认状态。双人同时领取时，保留获胜者的实际结果，不把已领取的气泡错误恢复。

请求超过 15 秒或网络/存储返回临时错误时，页面恢复显示，但保留原请求编号用于核对并重试。已有 SSE 成功回执时，以确认结果为准，不回退已保存的操作。此类错误不能直接断言服务器未写入；重试不得创建新编号。首次唤醒服务仍保留较长读取超时。

## 存档

临时页面状态不写入浏览器存档：本机只保存最新已确认快照和现有格式的待确认请求队列。刷新后先读取云端，按原编号核对待确认请求，不用未确认数值覆盖云端。
