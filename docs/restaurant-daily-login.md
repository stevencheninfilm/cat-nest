# 餐厅每日开店礼

进入餐厅时，每天首次显示「每日开店礼」，点击领取 300 小鱼干。小鱼干使用小窝金币的同一钱包，每个小窝两位主人共享一天一份，按北京时间 00:00 刷新。关闭后仍可从场景右上「每日礼」打开；已领取不再自动弹出。错过的日期不累计补发。

`restaurant.dailyLogin` 为可选的已领取凭据 `{day, claimedAt}`，旧存档不需要迁移或预写空记录。客户端只提交 `restaurant-daily-login` 和显示的 `day`，奖励金额和领取时间由服务端决定。跨天过期请求拒绝，不能自动占用第二天的奖励；同一 operationId 的重试沿用原回执。

奖励只增加 `state.coins`，不计入营业收入、完成料理、研发灵感、餐厅经验或小窝经验气泡。钱包达到上限时保留领取资格，不截断奖励。读取存档及进入小窝不会代替玩家领取。

点击立即显示等待状态，使用原有持久保存队列。未确认前不预加金币；断网和超时保留原操作标识自动重试。只有领取按钮暂停，关闭弹窗后可以继续营业。两位主人同时领取通过房间原子保存竞争，只发一份；收到明确冲突后读取已保存凭据，确认另一位已领则正常收敛，不提示假失败。

每日弹窗等待云端首份存档就绪，避让其他对话框及新手引导。记录弹出日期的本机偏好按现有小窝存储隔离，仅决定自动弹出，不作为发币依据。测试小馆沿用刷新恢复默认的隔离规则。

美术见 `public/assets/restaurant/daily-login-v1/manifest.json`，内置 imagegen 按现有主厨与用户提供的圆润角色参考生成。提示词见 `docs/assets/restaurant-daily-login-prompt.md`。
