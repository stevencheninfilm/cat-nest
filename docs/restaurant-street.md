# 餐厅街边与自然来客

- 空位出现后随机等待 8–15 秒再迎客；有等位顾客时等待 6.5–9.5 秒，仍保留离店和进店的动画间隔。切换面板、离开餐厅或关闭自然来客时不积攒补客次数；保存中的轮询不会反复重抽等待时间。
- 店满时偶尔有一组顾客等位，最多两组，每组一至两位。`restaurant-wait` 由共用 reducer 生成身份和等位时间，客户端不能指定猫猫或伪造时间。等位约 90–120 秒后离开，过期顾客不会被安排入座。
- `restaurant.waitingParties` 是可选的存档字段，旧存档默认空队列。有空桌后自然 `restaurant-arrive` 按 FIFO 取队首，在门口继续进店，保留猫猫身份。调试终端指定的单人、双人和单菜测试仍独立运行；重置调试场景也清空等位。
- 街边路人每隔一段随机时间出现，单人或结伴走过，不占用餐桌，不加入图鉴，不产生订单或收入。路人和聊天是本地瞬时场景，不写入房间或云端。
- 对话在路人、排队和已入座顾客之间按场景选择短句，轮流显示，最多两个气泡，自动收起。气泡不接管指针事件，也不重复触发读屏播报。
- 共用模块：`restaurant-street.js` 管理队列和来客时钟；`restaurant-street-ui.js` 管理路人和对话；`restaurant-street.css` 管理场景样式。

验证：`tests/restaurant-street.test.mjs` 覆盖队列上限、FIFO、身份与入场衔接、无额外奖励、旧存档、过期处理、非法输入、随机补客间隔、保存阻塞，以及聊天/路人不修改存档。
