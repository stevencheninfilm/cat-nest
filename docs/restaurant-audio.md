# 餐厅原声音频

2026-10-19：本地合成原创配乐和音效，未使用外部歌曲或采样。生成源为 `scripts/generate-restaurant-audio.py`（numpy，macOS afconvert 编码 AAC），资源位于 `public/assets/restaurant/audio/`。`manifest.json` 记录时长、采样率、音量峰值和校验值。

十二种 WAV 音效：点击、接单、工序操作、完成、送餐、收款、抽卡蓄势、翻牌、揭晓、升级成功、布置开工、布置完成。短按键声的播放增益低于结算和揭晓，避免连续操作刺耳。默认音乐音量 32%，音效 65%，右上角音符按钮可分别调节或静音。

`restaurant-audio.js` 管理单个 Web Audio 上下文、解码缓存和音轨；`restaurant-audio-ui.js/.css` 提供设置窗口。首次玩家手势后启播；研发室和抽卡切换独立配乐，650ms 淡入淡出，返回经营续接原播放位置。后台挂起、离开餐厅停止、销毁取消加载；文件失败可重试，音频不参与存档队列、不阻塞操作。设置只写入传入的存档隔离 preferences，键为 `catnest.restaurant.audio.v1`。

点击音来自人工按钮事件，操作音来自已接受的本地操作；抽卡音来自实际阶段切换。渲染和云端回执不会重放。音效限流、最多六个并发声部。AAC 为小体积配乐，WAV 为短音效，总资源约 2MB；每首首次使用时才加载，音效在首次手势后预解码。

验证包括解码状态、手势启播、重复点击、两曲切换与续播、静音和独立音量、后台与退出、慢加载取消、失败重试、文件完整性、抽卡阶段只触发一次，以及共享入口构建检查。
