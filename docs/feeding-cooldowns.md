# 食物冷却与餐食计时

以下是小窝的游戏时长，统一定义在 `src/state.js` 的 `FOOD_COOLDOWN_MS`，前端显示与服务器校验使用同一份规则。

| 食物 | 喂后冷却 / 在餐盘上保留的时间 |
| --- | --- |
| 清清饮水 | 30 分钟 |
| 冻干小鱼 | 45 分钟 |
| 猫咪肉条 | 1 小时 |
| 营养猫粮 | 1.5 小时 |
| 鲜虾小餐 | 2 小时 |
| 鸡胸肉 | 2.5 小时 |
| 幼猫慕斯 | 3 小时 |
| 三文鱼块 | 3.5 小时 |
| 鲜鱼罐罐 | 4 小时 |

男方与女方各自按上一份实际喂食的种类及保存时间计算冷却；选择其他食物、刷新或重新进入不会重置倒计时。服务器在冷却结束前拒绝重复喂食。餐盘左边男方、右边女方，各自到期后移除那一份食物和倒计时。小窝每天合计仍最多喂食 6 次，北京时间 0 点重置次数，跨日冷却继续。

双人奖励窗口仍为 4 小时，双方在该窗口内各喂一次即可完成，即使其中一份短时餐食已经吃完。换食物或反复补餐不会重开窗口或重复领取奖励。

旧存档的餐食根据已有食物种类与时间按新时长计算，不改金币、成长值、未领取气泡、次数、日记或喂食时间。新冷却记录保存食物键。旧冷却记录缺少食物键时，只从同一人的同一时间餐食推断；无法推断时保留原 4 小时限制。

此变更必须随统一发布同时更新前端与 Render 后端，避免网页显示已冷却、旧后端仍执行 4 小时限制。发布前先完成判官旧案件存档的保全，不在这个改动中直接重启线上服务。
