# 互动动画与视觉反馈（P0，2026-10-15）

本批已接入本地界面，尚未提交或发布。新增纯展示模块`src/interaction-feedback.js`和独立CSS；不修改经验、冷却、奖励金额、服务器校验或云端写入规则。主页仍沿用原有猫模型及动作、食物图集和成长爱心图，不增加WebGL场景或新的常驻动画循环。

## 已实现

- 全站按钮轻压、回弹；键盘操作同样可见。禁用控件不播放；移动超过10px取消回弹，猫猫转身/拖动保留原有手势。
- 投喂从所选食物的面板位置飞向猫猫，到达后出现短柔光和少量星点；抚摸在猫猫附近或手指触点出现柔光、爱心，轻触反馈更克制。休息使用短月光提示。
- 新成长气泡轻弹出现，领取用三颗现有阶段爱心沿弧线飞入成长条，到达后轻微亮起。相同操作ID不重复播放，保存确认沿用原有previewed门槛；失败按操作ID清理粒子与延迟到达效果。
- 弹窗内容轻柔淡入，食物选择轻微回应；状态增减沿用既有数字/增量反馈，增加很浅的背景过渡。
- 首页奖励列表按实际展示内容比较，无变化的确认/重绘不替换按钮，减少漂浮动画和点击焦点被打断。临时本机操作ID只补给展示层，不改变原有随机ID或存档内容。
- 粒子最多36个、每次3–6个，主要使用transform/opacity；结束、撤回、离开首页、切后台、页面隐藏/缩放、热更新销毁时回收。减少动态偏好即时关闭新增粒子、飞行和回弹；状态文字继续直接更新。沉浸陪伴保留原来的简洁模式。
