# 日常操作与后台保存

本次发布从线上提交 `9d472545e5b91eb7d99fcf076b83bafa16e9da7e` 建立独立分支，仅追加后台静默保存补丁。所有存档仍使用同一份应用，未纳入共享目录的其他未完成功能；3D 小屋保持暂未开放。实际部署编号与线上核对结果另记发布记录。

## 玩家体验

- 摸摸、喂食、逗猫、休息、换装和成长领取先在本机验证并反馈。上一笔上传不会锁住另一种合法操作。次数、冷却、余额以及同一气泡不能重复领取的规则保持生效。
- 收藏爱心立即切换。猫友邀请立即显示“邀请已送出”，只限制同一只猫在同一场景的重复邀请，可以继续查看或邀请其他猫友；正式入住、解锁提示和入场动画仍依据已确认快照。
- 正常保存、排队和保存成功不再反复显示联网提示、重绘喂食面板或打断小游戏。单人结果上传中可以直接再玩一局，实际奖励仍在云端核对后产生，成长仍需点击气泡领取。
- 首次读到可信存档后，实时连接重连不会重新盖住整个小窝。首次读取、明确的满员限制、切换身份时的保存保护，以及双人隐藏信息和对方动作等必要确认继续保留。
- 保存失败才显示错误提示。短暂断网、HTTP 超时、429 和服务端临时错误保留当前本地反馈与原请求编号，按原队列自动重试；明确拒绝或冲突才纠正对应画面，不重复发奖。

## 队列和性能

待保存请求继续按原存档缓存前缀及身份保存，服务器按原 operationId 去重。没有用临时数值覆盖已确认的浏览器存档，也没有改变服务端的规则、奖励、房间或数据结构。

新点击只计算新增操作，不再每次重算前面所有排队操作及整本日记；收到新的服务器快照时仍完整重算冲突。已确认快照只在变化时归一化和写入本机缓存，正常保存状态变更只刷新必要的错误提示。短暂失败期间的新点击不提前触发重复重试；晚到的 SSE 持久化回执可以立即释放下一笔请求。

队列保留原有 20 项容量保护。本机空间不足或队列已满时明确提示，不能假称操作已永久保存。浏览器缓存被清理、无痕环境不支持存储或页面强制终止前尚未确认的操作，不等同于已保存的云端存档。

- Node 22.23.3 独立发布副本回归：810 项，809 通过、0 失败、1 项真实 PostgreSQL 用例因环境未配置而跳过。此前共享快照的 851 项通过记录仅作为开发记录，不代表本次发布包含共享目录的其他功能。
- 按共享预览规定排除一项会监听额外前端端口的 Vite 集成用例，未另起预览服务。
- 带正式 API 地址的生产构建通过；共用入口检查覆盖 Steven、Evian、test、Todd、Xiao、Oliver、Ky 七个入口，只有一份入口脚本和资源。
- 新增回归覆盖连续照顾及领取、重复点击、20 项队列的增量计算、临时错误与重试间隔、超时后原编号去重、晚到的 SSE 回执、明确拒绝、断开的实时连接、收藏以及邀请的局部保护。
- 全量回归继续覆盖双人 HTTP/SSE、暗牌与奖励保护、存档隔离、刷新恢复和既有小游戏。
- 浏览器自动安全检查拒绝访问本地来源 `http://127.0.0.1:5174`，原因为已保存的来源权限禁止访问。没有绕过限制，没有把自动测试冒充浏览器或手机 FPS 验收。
