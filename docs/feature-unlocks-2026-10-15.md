# 功能等级解锁

| 功能 | 解锁等级 |
| --- | --- |
| 猫猫图鉴 | Lv.2 |
| 猫猫日记 | Lv.3 |
| 小猫表情 | Lv.5 |
| 手动动作 | Lv.6 |

所有存档使用 `src/feature-unlocks.js` 中同一份门槛。主页保留图鉴、日记、表情入口，未解锁时显示等级角标，点击说明条件；Lv.5 的表情面板可以查看动作解锁说明，Lv.6 才显示动作选择。触控、键盘和内部入口走同一检查，表情及动作执行处理器也会复核。

云端存档依据已确认的成长等级解锁，读取完成前保持锁定。尚未领取的爱心、仅本地预演的成长、失败或待确认的保存都不能提前解锁。测试存档依据其独立的本地状态，仍沿用同版规则。

图鉴邀请和日记收藏也由共用状态归约器校验，服务端使用同一逻辑。Docker 运行阶段已加入新规则模块。升级不会代替猫友各自的成就条件，也不会改变小游戏、庭院门槛及 3D 小屋暂未开放的状态。

等级限制不删除或重置数据。日记仍从领养和首次互动起持续记录，达到 Lv.3 后可查看早期回忆；已有猫友、日记、收藏、缓存与待提交队列继续保留。动作限制针对手动动作面板，吃饭、摸摸、休息等自然反应和新手引导继续工作。

测试覆盖等级前后 0.1 成长值边界、已确认快照、入口角标自动更新、Lv.5/Lv.6 面板差异、过期日记按钮、后端低等级请求拒绝、早期回忆记录与旧存档保留。原有收藏和邀请测试的成功场景补足对应解锁等级，继续检查原本的成就、去重、并发和存档隔离。

表情入口保持原有悬浮位置。锁定角标的定位只作用于图鉴入口，不覆盖表情按钮的绝对定位，避免低等级时按钮落到猫猫脚边。

本次发布在远端已发布版本 6cbd79f67543667840830280bd1c1057142778f3 上追加等级规则、表情入口修复和界面流畅性优化。保留该基线已有的猫咪手势、图鉴提示轮播、亲密度显示以及六个隔离存档；不复制共享目录其他未完成修改。所有入口使用同一构建产物。

测试与部署记录见 `release-fluidity-unlocks-2026-10-16.md`。本地复用共享预览，隔离副本只运行测试和构建。
