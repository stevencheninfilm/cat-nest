# 3D 小屋与机器人伙伴

本批为本地完成的探索模式，尚未发布。首页保留默认猫猫小窝，右侧「装扮」下方新增「3D小屋」；进入探索默认打开暖色小屋，可切换「科幻空间」。同一只主页 Mage Cat 沿用当前装扮和原作者动画，未更改骨骼或贴图。睡眠状态下不接受移动指令。

## 资产与表现

本项目新建的房间与机器人为程序建模的原创资产。视觉方向参考用户提供的等距房间、发光面板和机器人伙伴图片，以及 [Fab 场景套装展示](https://www.fab.com/listings/fe43531a-dd66-433a-8e4f-8c6eba1a292c)。没有下载或包含该套装的模型、材质、品牌角色或动画。已有 Mage Cat 继续作为获授权的游戏模型使用，来源与转换方式见 `docs/assets/mage-cat.md`。

可复用 GLB 位于 `public/assets/world/v1/`，使用 PBR 材质、不依赖外部纹理：

| 文件 | 大小 | 内容 |

| robot.glb | 642,168 bytes | 团团 T-01，独立头、悬浮身体、双臂、弹簧天线、发光眼睛/笑眼、HoverIdle / Greeting / HappyNod 动画 |
| home.glb | 1,388,596 bytes | 暖木地板、小窗、沙发、软床、音乐桌、夜灯、玩具球和门 |
| station.glb | 1,622,908 bytes | 金属地板、星图窗、控制台、充电站、休眠床、观星沙发、悬浮星球和气闸门 |

`node scripts/build-world-assets.mjs` 从 `src/world-assets.js` 重建。房间静态网格按父级和材质合并并索引化；可互动的父级及玩具球、门板、屏幕、灯环保留独立节点。机器人导出使用完整 VEC3 平移动画，保证 GLTF 兼容。

## 交互

- 轻点实际地板，用射线选择地面位置；A* 网格绕开家具与机器人，路径平滑只合并碰撞安全的线段。新点击替换旧路线，到达后才播放对应互动。
- 轻点物品或横滑底部互动栏：控制台亮屏、玩具球弹跳、床边闭眼小歇、沙发蹭蹭、灯环点亮、门板开合；猫猫靠近机器人后，团团转向猫猫、挥手点头、切换笑眼，猫猫抬爪回应。
- 直接轻点猫猫是短暂表情和星点反馈。拖动、多指、pointercancel 不视作点击；键盘方向键移动，底部按钮覆盖所有家具互动，Esc 返回。
- 自由走路与普通物品回应是本机视觉探索，不产生金币、成长或次数。新增「布置」将家具收藏、位置、转向、配色和小窝升级接入共用存档；家具照顾按钮在到达后沿用原照顾 action 和配额，详见 `docs/nest-decoration.md`。猫咪的即时走路位置仍由各端独立探索。
- 新视图按需加载、一个 WebGL 场景，上限 30fps、DPR 1.5、阴影 1024；主页在探索时暂停，返回后恢复。后台、关闭、切场景会撤销旧路线和动作，清理短粒子；减少动态偏好关闭粒子、悬浮和挥手等非必要动效，保留缓慢的目的地移动。

## 手机近景与原生动画优化（2026-10-15）

默认改为近景跟随；手机镜头约为原全景的2.17倍，320px小屏进一步适配。猫猫模型高度从1.45增至1.9世界单位，机器人统一放大8%，均未改动骨骼比例。顶部和底部控件压缩，前景延伸到浮层下方以减少留白；顶部「全景 / 跟随」可随时查看整个房间或返回角色近景。镜头跟随当前角色/互动对象的中点，正常模式平滑过渡，减少动态模式直接定位。机器人互动入口改为前侧斜向站位，并保持两张脸面向镜头的可见角度，避免放大后彼此遮挡。

核对了用户标注的[官方动画清单](https://www.fab.com/listings/710bc3f3-6bfd-4942-9eea-c7af4901bf03)和本地GLB中的九段原动画。探索自动使用 Idle、Walk、Run、Turn Left、Turn Right、Attack、Special Attack：大幅换向先播放原转身动作，较远且精力足够的路线采用Run，短路/疲倦/减少动态采用Walk；机器人和玩具使用Attack，控制台使用Special Attack。到达才播放互动，并按真实片段时长和速率收尾，修复先前约4.79秒的慢速Attack被3.6秒定时截断。Hit（包内名Hurt）与Death保持在原模型中，探索自动交互不调用。机器人挥手、点头播放两轮以配合猫猫抬爪。

新模块 `src/world-camera.js` 和 `src/world-animation.js` 只处理镜头与动画选择；`src/world-cat.js` 提供原片段时长。此轮未修改共享主页、原猫行为控制器或动画播放器，也未重建GLB。

`node --test tests/world-framing.test.mjs tests/world-layout.test.mjs` 9项通过；新增投影检查覆盖320/390/430px角色高度、双角色脸部间距、全景边界、横竖屏、镜头过渡和减少动态，以及原动画选择。共享5174中实际观察到 `turn_left → walk → special_attack`、长路线Run、途中换目标、机器人Attack与扩大后的双角色站位。320px与390px近景/全景均查看，无全页横向溢出；全景点地面到达正常，减少动态时互动为Idle，未发现启动或运行error。完整业务验收仍按上文合并后清单执行，不进行真实养成提交。

视觉方向来自用户提供的[Retro Arcade参考展示](https://www.fab.com/listings/8ca73125-0f0d-49da-9abc-fcdea108812c)及零食吧图片。本次通过项目自己的程序建模制作，没有下载或复制商店模型/纹理。新GLB为 `public/assets/world/v1/arcade.glb`（2,325,828 bytes），包含红紫格墙、双色地砖、粉色霓虹灯、CATCADE像素招牌，以及街机、抓娃娃机、点唱机、台球桌、饮料吧、爆米花车、休息椅和回收箱。现有机器人与获授权猫模型继续复用。
