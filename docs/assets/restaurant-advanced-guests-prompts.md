# 高级顾客资源与解锁规则

本批使用内置 `image_gen`，直接使用用户提供的游戏截图作为圆润造型和线条风格参考。12 位高级顾客各有正面与背面，项目资源位于 `public/assets/restaurant/guests-v2/`。原 16 位顾客保持普通来客。

解锁采用全部满足：小馆等级、指定菜谱已解锁、指定员工已雇佣、指定设施已升级、指定场景正在布置使用。仅拥有场景不算正在使用；更换装扮后不再随机出现相应顾客，已到访记录和正在用餐的顾客保留。普通菜谱遵循共用等级与旧存档权限；金色招牌料理必须实际购买。

到访记录由接客动作保存到当前餐厅的 `seenGuests`；旧存档仅从仍在店里的顾客补记，不推测过往到访。测试存档沿用刷新重置。
