# Nekueda Mage Cat in Cat Nest

Purchased listing: https://www.fab.com/listings/710bc3f3-6bfd-4942-9eea-c7af4901bf03
Author: Nekueda. License: Fab Standard License. The original package includes a NoAI restriction. The model is used as an authored game asset, with deterministic format conversion and texture resizing. No generative image/model processing or training is involved.

The private local sources are under `artifacts/licensed/mage-cat/`, which is ignored by Git. Source FBX, Unity package, texture archive, and documentation must not enter the public source repository. Only the curated optimized assets live in `stevencheninfilm/cat-nest-data/assets/mage-cat-v1/`. The backend serves a fixed allowlist for the game; it cannot fetch arbitrary files or expose source packages, room files, credentials, or upstream errors.

`prepare-mage-cat.mjs` preserves all three authored LODs, the skeleton and the nine non-TPose animations. It merges identical vertices, normalizes FBX weights to the four-influence web renderer, and optimizes redundant animation keys. Textures are resized to 1024 pixels for the coat and 512 for the facial planes and wand; their authored artwork and transparent face layers are retained. The default model is the author's black cat, purple outfit, amber eyes and yellow wand. The exported geometry/animations are 4,611,856 bytes; all 43 game files total 5,871,920 bytes.

The original body and clothing variants remain independently selectable, alongside three eye colors and three wand colors. The appearance is one validated cloud action (`dress`) and produces no currency or growth reward. Existing version-one saves receive the original default appearance while retaining progress and history. Canceling the editor restores the saved appearance. Successful edits become visible to both roles after a GitHub commit.

The home behavior controller (`src/cat-behavior.js`) derives mood from the current decayed hunger, mood and energy values, with explicit sleep taking priority. It uses local device time for morning (06:00–11:00), day (11:00–18:00), evening (18:00–22:00) and night (22:00–06:00). This is local presentation; autonomous behavior never changes sleeping, care quotas, growth, currency or cloud history.

Seven authored clips now participate in care: Idle, Walk, Run, Turn Left, Turn Right, Attack and Special Attack. Between 5–13 second quiet gaps, an awake cat may look around, tread in place, nuzzle or wink; an energetic cat can also run in place. Weighted choices exclude the last two unattended activities where alternatives exist. Fatigue and night extend gaps to 12–24 seconds, suppress unattended running and add yawning or temporary dozing. The room and model lighting also soften at night. Temporary dozing is visual only and does not spend a rest allowance or claim sleep rewards.

Petting and food use authored facial textures plus small outer-group movements. Low mood favors comfort, fatigue favors a gentle response, and play varies between wand magic (Special Attack), a playful wand swipe (Attack), and a short chase (Run). Hungry, tired and nighttime play stays gentle. Touching the cat while all care actions are cooling down still gives a local facial response, without granting another reward. Dialogue also follows needs and time. Blink timing, gesture gaps and playback rates vary rather than following fixed cycles.

`src/mage-cat-player.js` plays original tracks unchanged, repeats locomotion when needed, uses the actual clip duration and playback speed for completion, and blends back to Idle. Repeated interactions can restart the same clip; faded actions are stopped. Manual rotation yields to the user's drag. Hidden views pause and clear pending gestures rather than replaying a backlog. Reduced motion keeps the cat on the slowed Idle clip while preserving expression feedback. The court avatar opts out of autonomous home gestures.

All procedural movements are assigned to the outer group on each frame; they never change the author's facial attachment nodes or bone rotations, preventing accumulated pose drift and clipping between face, skin, hair and hat. Death and Hurt are preserved in the downloaded model but are not repurposed as sleeping or care animations. The renderer chooses a single LOD, caps resolution and runs at 30 fps. For manual verification, use the existing shared preview at `http://127.0.0.1:5174/tests/cat-behavior-preview.html`; the scenario controls do not write to the game save. `tests/cat-behavior.test.mjs` covers mood/time boundaries, five-minute unattended behavior, care priority, safe sleep, reduced motion, clip timing and playback cleanup.

To reproduce conversion, use `node scripts/prepare-mage-cat.mjs <private-source-dir> <private-output-dir>` with three and sharp available. `SHARP_MODULE_ROOT` may point to an installed bundled Node dependency directory. Do not execute scripts or editor extensions from downloaded packages.

For local development, `npm run dev:client` or `npm run dev` serves the curated files from `artifacts/licensed/mage-cat/processed/` directly through Vite at `/api/pet-model/mage-cat-v1/`. No separate port-9095 asset process or GitHub credentials are needed. The development middleware uses the same fixed game-file allowlist as production; it does not expose source archives. If the local optimized model is absent, the normal API proxy remains in use. Production builds keep their configured model API unchanged.
