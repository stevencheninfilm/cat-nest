# 本地时间与小窝小事

所有入口使用同一份 `src/` 和同一构建。此功能不改房间绑定、浏览器原有缓存键、待提交队列、照顾资源或云端数据结构。

## 四时段氛围

按当前设备本地时间取时，不读取服务器时区，不需要定位权限。

| 时段 | 本地时间 | 呈现 |
| --- | --- | --- |
| 早晨 | 06:00–11:00 | 明亮奶油色晨光、轻柔光束、早安问候 |
| 白天 | 11:00–17:00 | 清透日光、自然猫咪灯光、晒太阳问候 |
| 黄昏 | 17:00–21:00 | 蜜桃晚霞、暖色灯光、放松问候 |
| 深夜 | 21:00–次日 06:00 | 冷色窗光、暖灯、月牙星点、安静动作与问候 |

首页标题下显示本地时段与时分，每分钟更新；跨时段和从后台回来立即重新计算。房间和 3D 猫咪的色调平滑过渡，减少动态效果偏好会关闭位移动画与过渡。时钟、猫咪心情和问候共用时段定义，减少错位。日记的小窝文案按本地日期选取，不同日子可看到不同片刻。

## 偶发小事

打翻线团或空纸杯、发现纸星星/羽毛/缎带、突然凑过来撒娇。用现有温和猫咪动作、3D 小道具及约 6.5 秒的轻提示呈现，无弹窗、无音效、无必须点击的处理流程。礼物事件用带蝴蝶结的礼盒承载小发现。事件中照常可以摸摸、喂养和打开其他功能。

- 在首页安静陪伴至少 25 秒后才有机会，最多每 60 秒检查一次，触发概率 12%。
- 两次事件至少间隔 15 分钟；同一设备的该存档，每个本地自然日最多 3 次。相邻事件尽量不重复类型，同类文字也尽量变化。
- 深夜只挑安静的礼物和撒娇。睡觉、拖动猫咪、手动表情/动画、照顾反馈、对话、加载、保存、合作庆祝、沉浸模式、小游戏和其他弹窗期间都避让。
- 触摸首页或收到正常照顾反馈会立即收起事件提示；切后台、切页面不会补播错过的事件，返回后重新等待安静间隔。
- 已发生的事件与抽取检查时间存在 `runtime.localStorage` 下的 `catnest.life.v1.<roomId>`。遵循 Steven 原缓存空间、Evian 前缀及测试适配器隔离，保存最近 12 条，日记显示最近 6 条本机小事。刷新不会重抽同一分钟，也不会重置冷却与当日次数；时钟回退不重置次数。
- 礼物是场景发现，事件不直接变更金币、亲密度、经验、照顾次数或共同纪念，不向照顾 API 发请求。

`/test/` 演示控制台提供四时段和三种事件的手动预览，调用的仍是共用氛围/动作/UI。预览不写本机事件记录或云端数据；恢复自动时间或刷新会回到真实本地时间。其他入口不注册该调试消息。

## 验证

`tests/nest-life.test.mjs` 覆盖四时段边界、问候一致性、每日文案、概率与检查节流、刷新冷却、每日上限、午夜、时钟回退、后台与忙碌避让、动作打断、损坏缓存和存档隔离。与既有猫咪行为、对话及共用入口测试一起运行，构建继续执行共享入口一致性检查。

## 3D 线团与礼物

`src/nest-life-props.js` 构造实际网格：线团有四层交叉绕线与弯曲拖尾；礼盒有圆角盒身、独立盒盖、交叉缎带与立体蝴蝶结。线团和礼物比原 CSS 图形放大，放在猫咪脚边右侧，按现有正交相机的宽度收缩以避免窄屏裁切。进入、淡出、6.5 秒消失及交互打断统一接入小事系统，减少动态效果时取消滚动和弹跳。

直接复用猫咪的 Three 场景、光照和渲染器，不增加 WebGL 画布；道具不跟随猫咪旋转。模型不可用时显示简洁的 emoji 作为降级。`tests/nest-life-props.test.mjs` 验证网格细节、手机和宽屏的完整取景、切换与打断、减少动态效果和资源释放。

线团按用户红线参考，从小窝右上方沿弯曲的抛物线进入，约 1.55 秒落到猫咪脚前。轻弹后猫咪伸出空着的左爪拨动，线团在接触时才滚开；猫咪用原有 Run / Walk 动作追着玩，再回到原位。全部动作共用 `nest-yarn-play.js` 的时间轴，约 5.8 秒完成，仍沿用 6.5 秒小事时长。

这段动画临时把现有画布延伸到小窝范围，投影保持猫咪原有像素位置和大小，结束或打断后立即恢复。伸爪只在空着的左臂骨骼辅助链上增加可还原的姿态，每帧在原动画更新前恢复，不改脸部、帽子和持杖侧，没有骨骼漂移累积。地面阴影随距离变清晰，减少动态效果时直接呈现停稳姿态。取景一致性、真实骨骼还原、接触前线团静止、追跑衔接及每阶段打断由测试覆盖。

运行 `node scripts/build-life-props.mjs` 可以从同一套几何生成器导出独立的模型资产，均为内嵌缓冲的标准 GLB，无外部贴图依赖：

- `public/assets/nest-life/v1/yarn.glb`
- `public/assets/nest-life/v1/gift.glb`
- `public/assets/nest-life/v1/cup.glb`
