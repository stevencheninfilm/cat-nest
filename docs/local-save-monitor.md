# 本机存档监测后台

访问 **http://127.0.0.1:5174/monitor/**，复用现有共享本地预览，无需新增服务、端口、口令或付费资源。

## 信息范围

- Steven、Evian、Todd：从现有线上 API 读取已保存的等级、等级进度、成长值、猫爪币、亲密度、三项状态、休息状态、待领取气泡、图鉴入住数、双方喂食、照顾者绑定数、修订号和最后保存时间。
- `test`：浏览器临时调试空间，每次访问重置，没有统一的云端等级；后台标注其特性，不使用另一份模拟等级冒充真实进度。
- 前后端发布 SHA 和登记入口覆盖情况。四个入口继续共用同一功能版本，各自的数据、角色和待保存队列独立。
- 读取成功只表示云端可读，不表示玩家当前在线；照顾者数量是已绑定人数。

可搜索名字、按等级或更新时间排序，筛选需要照顾的小猫与读取异常。任一需求低于 30 时列入需要照顾。已领取成长与未领取气泡分别统计，监测不会领取奖励。

## 访问与刷新

- 仅开发模式挂载 `/monitor/` 与 `/__monitor/snapshot`，只允许本机回环地址、5174 端口和同源请求。拒绝局域网、非本机 Host、跨站来源及所有写操作。
- 页面打开时每分钟刷新；隐藏时暂停自动采集，关闭后停止。服务器合并同时请求并缓存 30 秒，避免每次点击重复读取云端。
- 单个存档读取失败不影响其他存档。曾成功读取的存档保留上次快照并显式标记过期；从未读到的存档显示不可读，不伪造零值。
- 只请求已登记的固定线上地址，不能通过请求参数指定房间或外部网址。不回传完整历史、纪念日志、房间 ID 或服务端凭据。
- 新增存档只需正常注册 `config/homes.json`，监测和共享构建检查都会自动纳入。后台不会建立、复制、重置房间或写入存档。
- 生产构建不生成监测页面和监测脚本，不修改线上服务或 Render 配置。
