# 猫猫的场景邀请和对话

猫猫图鉴只收集一次，入住每个可用场景需分别免费邀请。图鉴保留全局收集状态，庭院菜单显示当前场景的邀请数量。点击尚未来访的虚线轮廓，可查看成就或邀请已经收集的老朋友。

原有 `collection.invited` 保持一猫一条的永久图鉴收据；新增可选 `collection.sceneInvited` 存储每个场景的邀请收据。旧收据继续代表车站的邀请，不改写原记录，不自动生成其他场景的来访。首次在其他场景邀请会同时写入全局收据及相同操作编号的场景收据；后续邀请只新增场景收据。重复邀请不增加图鉴数、成就进度、金币、经验或照顾次数。

前端只根据已确认的共享快照播放对应场景的入场动画。云端及本地预览均通过永久收据识别操作编号，短期操作日志滚动后仍可安全重试；不同场景不得复用同一个操作编号。Steven、Evian、Todd 与测试入口继续共用这套实现，存档上下文保持隔离。

点击已来访猫猫会保留原来的触摸反应并显示独白；睡眠姿势显示 `zzz…`。9 组特殊朋友会轮流说话，一次点击推进一句，聊天期间点击任意已来访猫猫均可继续。另一半尚未收集或尚未来访当前场景时，会说等朋友的话。对话进度仅保留在本次庭院界面，切换场景或离开会清除，无计时自动推进，无网络生成请求。
