# 松饼、布丁、抹茶奶盖、汉堡工序美术

生成方式：内置 ImageGen（`image_gen.imagegen`），2026-10-18。每张图独立生成，明确传入参考图并请求透明背景；没有调用 API、替换原成品图或使用额外预览服务。

参考为项目中对应的 `foods/{pancake,pudding,matcha,burger}.webp`、`kitchen-v3/qa-props.webp` 与 `restaurant-scene.webp`。保持原菜品造型、奶油/鼠尾草绿器具及暖棕描边。本轮没有新增猫角色。

22 张六帧原稿均为 1536×1024、三列两行，提示词要求容器位置稳定、工具和食材独立动作、无文字/人物/场景背景。完整提示词、实际参考路径和原始生成文件路径保存在 [generation-record.json](generation-record.json)。压缩原稿另存 `sources/`，原 PNG 也保留在生成目录。

运行 `scripts/prepare-restaurant-kitchen-v4.py`，将原稿裁为六帧，按器皿底部对齐并编码为 384×384 透明循环 WebP，每帧 170ms。静态操作道具为 512×512。汉堡最后装盘复用叠放原稿的收拢动作，得到 23 个动画与 19 件道具。成品和员工端菜仍使用原来的 foods 图。

| 菜品 | 新动画 |
|---|---|
| 蜂蜜松饼 | 取料、调面糊、抹黄油、倒面糊、翻面煎饼、淋蜜装盘 |
| 焦糖布丁 | 取料、熬焦糖、过滤入模、隔水蒸制、脱模装饰 |
| 抹茶奶盖 | 取料、过筛、茶筅搅拌、打发奶盖、调抹茶奶、铺奶盖 |
| 芝士汉堡 | 取料、压肉饼、烤面包、煎肉融芝士、叠汉堡、整理装盘 |

复用：布丁搅拌使用蛋奶面糊动画；温奶使用既有打奶泡动画；汉堡洗菜和切菜使用三明治动画。全部由 `src/restaurant-kitchen-assets.js` 共用映射到场景、教程、终端和工序后台。

[qa-props.webp](qa-props.webp) 为美术总览；[manifest.json](manifest.json) 记录实际文件尺寸、帧数、透明比例、去重帧数、循环和体积。工序后台会按真实状态显示走位、等待、到站加工蓝环、送餐与返程；图片预览不改变订单。
